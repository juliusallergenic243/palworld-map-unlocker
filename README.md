## ❓ Frequently Asked Questions

**Does this get me banned?**
This is a single-player tool. You use it on your local save files. It does not connect to online servers in a way that risks your account.

**Does the map stay unlocked?**
Yes. The changes stay on your save file until you decide to revert them or start a new game.

**Why does my computer show a warning?**
Windows protects you from software it does not recognize. Since this is an open-source tool, it lacks a standard signature. You can click More Info and then Run Anyway to bypass this if you trust the source.

**What happens if I update the game?**
Game updates sometimes change how save files work. This tool should remain compatible with most updates. If the tool stops working, check the download page for a newer version.

**Does this work on multiplayer servers?**
This tool modifies local save files. It works best for single-player worlds. Using it on dedicated servers requires server-side access and might not work as intended. 

## 📝 Troubleshooting

If you run into errors, check these common items:

- Ensure the game is fully closed. The tool cannot change files that the game is currently using.
- Check your permissions. Sometimes Windows restricts software from writing to folders. Run the tool as an administrator if it fails to save changes.
- Verify your path. Ensure you selected the specific save folder containing your WorldData.sav file.
- Restart your computer. This clears temporary issues with file locks.
